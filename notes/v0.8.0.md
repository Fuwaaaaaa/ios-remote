# v0.8.0 — Synthetic Device Mode

**Released:** 2026-05-13

## Highlights

- **`--synthetic` flag** — Run ios-remote end-to-end without a physical iPhone.
  Generates a live 30 FPS iPhone-shaped mock screen (status bar + clock + app
  grid + rotating notification banner) and streams it through the same
  `FrameBus` the real screenshotr capture loop uses. Display / recording /
  screenshot / OCR / AI vision / session replay / Stream Deck all light up
  without hardware.

- **Dummy WebDriverAgent stub** — When `--synthetic` is on, a tiny HTTP server
  binds `127.0.0.1:8101` and accepts the WDA tap / swipe / long-press calls
  ios-remote's macro engine makes. Inputs are logged and acknowledged with
  HTTP 200 — every macro REST path returns success instead of the usual
  "WDA not reachable" error.

- **Synthetic subtitles** — `/api/subtitles` is populated with rotating
  placeholder lines every 5 s so the dashboard's Subtitles card has content.

## Quick start

    cargo run --release -- --synthetic
    open http://127.0.0.1:8080

## Compatibility

- Default builds (without `--synthetic`) keep the v0.7.2 retry-on-no-device
  behavior exactly as before.
- `--synthetic --device <UDID>` warns and ignores `--device`.
- `--synthetic --diag` runs `--diag` as before (synthetic ignored).
- No new dependencies. The renderer reuses the 5x7 bitmap font already
  shipped in `src/features/stats_overlay.rs` (also used by the subtitle
  renderer).
